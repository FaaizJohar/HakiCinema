# HakiCinema (HakiBox) 🎬

High-performance anime streaming platform built with Next.js 16 (App Router), Firebase Admin SDK, Tailwind CSS, and edge caching.

## ✨ Features
- **Next.js 16 App Router** with React 19 & Turbopack
- **Firebase Authentication & Firestore Admin SDK**
- **Edge Middleware Security** protecting admin routes
- **Automated Dynamic SEO & AI Discoverability** (JSON-LD schemas, sitemaps, robots.txt)
- **HLS Video Streaming Engine** with custom overlays & quality controls
- **Full Responsive Design** with custom dark aesthetic & smooth transitions

## 🚀 Getting Started

First, install dependencies:
```bash
npm install
```

Configure your environment variables in `.env` (refer to `.env.example`).

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

## 🌐 Deploy to Vercel
Deploy seamlessly using Vercel:
1. Import this repository into [Vercel](https://vercel.com).
2. Add your environment variables from `.env.example`.
3. Click **Deploy**.
